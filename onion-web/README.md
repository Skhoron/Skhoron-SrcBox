# Onion-Web.py

Выбирает случайный живой .onion-сайт. Адреса берутся из Ahmia или из твоего файла/URL, проверяются через Tor, и выводится один (или несколько) рабочих.

## Требования

- Python 3.8+
- Запущенный Tor: Tor Browser (SOCKS на порту 9150) или демон tor (порт 9050)
- Библиотека requests с поддержкой SOCKS:

```
pip install "requests[socks]"
```

## Использование

```
python onion_random.py -a                    # случайные сайты через Ahmia
python onion_random.py -a -k news -k tech    # искать в Ahmia по этим словам
python onion_random.py -a -n 5 -x shop       # 5 штук, без слова "shop"
python onion_random.py -f onions.txt         # адреса из файла
python onion_random.py -u https://example.com/list.txt   # адреса по ссылке
python onion_random.py -a --port 9050        # если используешь демон tor
```

## Опции

| Флаг | Что делает |
|---|---|
| `-a`, `--ahmia` | брать адреса из поиска Ahmia |
| `-f`, `--file` | файл с адресами (любой текст, адреса вытащатся сами) |
| `-u`, `--url` | ссылка на текстовый список адресов |
| `-n`, `--count` | сколько рабочих сайтов вывести (по умолчанию 1) |
| `-k`, `--keyword` | оставить только сайты со словом в тексте страницы; с `-a` также используется как поисковый запрос. Можно повторять |
| `-x`, `--exclude` | убрать сайты со словом. Можно повторять |
| `--port` | порт SOCKS-прокси Tor (по умолчанию 9150) |
| `--timeout` | таймаут на один сайт в секундах (по умолчанию 25) |
| `--sample` | сколько адресов проверять за раз (по умолчанию 40) |
| `--threads` | число параллельных проверок (по умолчанию 10) |

## Как работает

1. Собирает onion-адреса: из Ahmia (если `-a`), из файла и/или по URL.
2. Оставляет только v3-адреса (56 символов) и убирает дубли.
3. Перемешивает список и проверяет адреса пачками через Tor.
4. Для живых сайтов читает заголовок и первые 200 КБ страницы, применяет фильтры `-k` и `-x`.
5. Печатает найденные сайты и останавливается, когда набрал нужное количество.

## Ограничения

- Разбор HTML Ahmia не является официальным API. Если вёрстка поменяется, поиск перестанет работать.
- Ahmia не индексирует значительную часть onion-сайтов, так что выборка не равна всему Tor.
- Запрос к Ahmia идёт напрямую, без Tor. Проверка сайтов идёт через Tor.
- Скрипт ничего не скачивает и не открывает сайты полностью, только читает начало страницы. Тем не менее, открывать найденные ссылки стоит только в Tor Browser с настройками безопасности не ниже «Стандартного».
- Фильтры работают по тексту страницы, так что они не гарантируют безопасность контента.
- Не тестировался против живой сети. Возможны баги.

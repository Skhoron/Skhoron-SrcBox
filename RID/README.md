# RID

Генератор коротких случайных идентификаторов. Задаётся стойкость в битах (128-256), длина строки считается под неё. Две реализации с одинаковым поведением: Rust и Python.

Часть [Skhoron-SrcBox](https://github.com/Skhoron/Skhoron-SrcBox).

## Зачем

Идентификатор должен быть таким, чтобы его нельзя было ни угадать, ни получить случайным совпадением. При 128 битах шанс угадать конкретный ID равен 1 к 2^128 (около 3·10⁻³⁹), а совпадение двух ID среди триллиона выданных около 10⁻¹⁵. 256 бит дают запас сверх этого.

## Алфавиты

| Режим | Символов | Бит на символ | 128 бит | 192 бита | 256 бит |
|-------|----------|---------------|---------|----------|---------|
| по умолчанию | 93 | ~6,54 | 20 | 30 | 40 |
| `--safe` | 64 | 6 | 22 | 32 | 43 |

Режим по умолчанию: A-Z, a-z, цифры 1-9 и 32 спецсимвола ASCII. Ноль исключён, чтобы его не путали с `O`.

Режим `--safe`: A-Z, a-z, 0-9, `-`, `_`. Строка без изменений вставляется в URL, имя файла и командную строку.

## Rust

```
cargo run --release -- 128
cargo run --release -- 256 --safe
```

Сборка: `cargo build --release`, бинарник в `target/release/rid`. Тесты: `cargo test`.

Случайные байты берутся из системного генератора через `getrandom`. Лишние байты отбрасываются, поэтому все символы алфавита равновероятны.

## Python

```
python3 python/rid.py 128
python3 python/rid.py 256 --safe
```

Нужен Python 3.6+, сторонние пакеты не нужны. Используется модуль `secrets`.

## Вывод

Строка идёт в stdout, а число бит и длина идут в stderr. Поэтому `rid 128 > id.txt` сохранит только сам ID.

В режиме по умолчанию в строке бывают `"`, `'`, `\`, `$`, `` ` ``. При вставке в shell экранируйте её или читайте из файла.
